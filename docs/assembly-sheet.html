GPS Tracker Wiring

ESP32-S3 DevKitC-1 build · rev 1 · 2026-10-09 · pins match include/config.hpp

Bench sheet for assembling the tracker on a breadboard. One table per module, read left to right: module pin, wire, where it goes. Wire colours follow the legend so a photo of the board can be checked against this page.

Before the first wire
  • 3.3 V logic everywhere. The ESP32-S3 pins are not 5 V tolerant. GNSS modules and the OLED output 3.3 V logic even when fed 5 V, so TX/RX/SDA/SCL go straight in.
  • Measure the shield's "3V" rail first. Listings disagree whether it is 3.0 V or 3.3 V. Below 3.1 V, feed the OLED and BMA400 from the devkit's 3V3 pin instead and give the SD module 5 V (level-shifter type only).
  • Never join the devkit's 3V3 pin to the shield's 3V rail. Both are regulator outputs. The devkit gets 5 V on its 5V/VIN pin and makes its own 3.3 V.
  • BIGGA GSM: TX is 5 V logic and the modem draws 2 A bursts. Put 6.8 kΩ from the board's TX pin to GND before it reaches GPIO18. No external capacitor is needed: the board has 100 + 10 + 1 µF at its VCC input and several hundred µF on the modem rail. Use short 22 AWG or thicker wires for VCC/GND. The 1000 µF is only a fallback across VCC/GND if the boot line ever shows BROWNOUT.
  • One ground. Every GND goes to the shield's GND. Star it at the shield, not daisy-chained through modules.
  • Check 18650 polarity twice before inserting. A reversed cell burns the shield's protection IC.
  • Antennas. GNSS patch antenna face-up with a sky view; keep the GSM antenna cable away from it.

GNSS: Foxeer M10Q-250 (or Beitian BE-220)

MicroSD SPI module

J4 · SPI2

Pins run straight along the devkit header: CS 10, SCK 11, MOSI 12, MISO 13. Two kinds of module exist. The small bare board (no regulator, 6 pins) takes 3.3 V. The larger board with a level shifter (LVC125A) takes 5 V on VCC. Either way the four signals go directly to the devkit. Card: 8–32 GB, FAT32.

BIGGA GSM (SIM800C) board

J2 · UART2 · R3 6.8 kΩ on TX · LED1 + 1 kΩ on NET

Silkscreen names on the board: NET VSS PK RX TX GND on one edge, SPN SPP MICN MICP RING DTR on the other. VSS is the 5 V supply input here, not ground; confirm with the meter that the pin marked GND beeps against the SMA shell and VSS does not. TX idles at 5 V: the board's level shifter is referenced to VCC, so a 6.8 kΩ resistor from TX to GND is required before GPIO18 (gives about 3.0 V). RX needs nothing extra. BOOT is the modem's PWRKEY; the board does not start by itself, the firmware holds BOOT low for a second when the modem is silent. Feed VCC with 5 V only: 9 V damages the ESP through the shifter, 3.3 V is below the regulator's dropout. Nano-SIM, PIN disabled, 2G coverage confirmed, full-size SMA antenna.

BMA400 (CJMCU-400), when it arrives

J6 · I2C 0x14 · INT1 → GPIO6

Shares the I2C bus with the OLED. INT1 lands on an RTC-capable pin so it can later wake the chip from deep sleep. INT2 stays unconnected. Address is 0x15 if the board's SDO/ADR pad is tied high.

Assembly order with checks

Add one module at a time and watch the console after each. The expected log line comes from the firmware; if it does not appear, stop and fix that module before adding the next. Ticks are remembered in this browser only.

  1. 5V rail: 4.9–5.2 V · 3V rail: 3.0 or 3.3 V (decides OLED/SD supply)
  2. I (..) tracker: Boot: reset reason power-on (1) I (..) console: Commands on UART0; type 'help' LED white, then amber once the GNSS is added
  3. type diag → battery error counter stays 0; the system page shows the cell voltage
  4. I (..) tracker: State BOOTING -> ACQUIRING I (..) tracker: State ACQUIRING -> TRACKING (sky view, 30–90 s cold) Wrong baud: 'rej' grows in diag → set gnss 1 / save
  5. I (..) ssd1306: Display ready at address 0x3C Tracking page with state, satellites, position
  6. I (..) sdcard: Mounted /sdcard: NNNN MiB 'SD ok' on the screen; TRACKS/YYYYMMDD.CSV appears after the first record
  7. I (..) sim800: Modem silent at every baud rate, pulsing PWRKEY (1/3) (normal: the board needs the pulse) I (..) sim800: Modem answered at 9600 baud (or 115200) I (..) uplink: GPRS up on APN internet 'sent:' grows on the system page; the point appears in Traccar
  8. nmea rx N rej 0 silences 0 | log ok N drop 0 err 0 | up ok N ... | stack free: gps … display … logger … uplink … ui …
Sources in the repository: docs/HARDWARE.md (power tree, GPIO map), docs/kicad/gps_tracker.kicad_sch (schematic, ERC clean), include/config.hpp (the pin constants the firmware uses). Module pin orders on the breakout boards vary by vendor; the tables name pins by function, so follow the silkscreen.
